## 目标

把预约规则抽象为符号转移系统，用 Z3 做 k 步有界模型检验（BMC），证明在 k 步内
"每个时段至多一个预约""只有 Interviewing 申请能新建预约""已预约时段不可删除"不会被违反；
并演示放宽一条守卫后求解器能找到反例轨迹。

## 模型

- 规模：2 个申请（同一雇主）、2 个时段，k = 6 步。
- 状态变量（每步 t 一份）：`status[a][t] ∈ {Pending, Interviewing, Rejected, Accepted}`（`EnumSort`）、
  `booking_of_app[a][t] ∈ {none, s0, s1}`、`slot_exists[s][t]: Bool`。
- 动作（每步恰选一个，`action[t]` 为枚举）：`set_status(a, S)`、`book(a, s)`、`delete_slot(s)`、`noop`。
- 守卫严格照抄实现：book 需要 Interviewing、该申请无预约、时段存在且未被任何申请预约；
  delete 需要时段未被预约。守卫不满足时状态不变（对应"失败不部分修改"）。

## 检验

| ID | 性质（对所有 t ≤ k） | 期望 |
|---|---|---|
| B1 | 不存在两个申请预约同一时段 | `unsat`（找不到违反） |
| B2 | 若 t 步发生 book(a,·) 成功，则 `status[a][t] = Interviewing` | `unsat` |
| B3 | 已预约时段在之后任一步仍存在 | `unsat` |
| B4 | 预约一旦存在，状态变化不清除它 | `unsat` |

负向演示（各一个测试，期望 `sat` 并打印反例动作序列）：

- N1：去掉 book 守卫里的"时段未被预约" → B1 被违反；
- N2：去掉 delete 守卫 → B3 被违反。
