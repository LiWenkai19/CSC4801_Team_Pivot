## 已完成什么

- 登录主页按角色分流：雇主可进入工作流及公司资料；候选人按钮显示“尚未实现”。
- 公司资料可查看、编辑和保存；只提交修改的字段，描述可以清空。资料缺失时引导到现有补填页。
- 职位可新建、查看、编辑、删除；技能按逗号拆分，留空可清空要求。有申请或面试时段时，删除提示冲突并保留职位。
- 职位详情显示申请人身份、技能、分数、状态及预约时间。沿用后端评分和排序，不在前端另算分数；预约明确显示 UTC。
- 状态只能选择 Pending、Interviewing、Rejected、Accepted，保存后立即更新该行。切换状态不清除预约。
- 已处理加载、空列表、空白输入、失败重试、输入保留、提交禁用、未登录、角色不符、403、404、409 和 422。内容按文本展示，避免执行用户填写的 HTML。

页面使用原生按钮和表单，符合规划中的最简界面范围。

## 重跑浏览器回归

前置：已安装后端依赖，配置有效的 `backend/.env`，本机 PostgreSQL 可用，配置账号可创建及删除独立测试库。以下命令在仓库根目录的 PowerShell 中执行，先激活项目 Python 环境：

```powershell
conda activate SYManage
npm.cmd --prefix frontend run build
$employerTestTools = Join-Path $env:TEMP 'csc4801-employer-test-tools'
npm.cmd install --prefix $employerTestTools --no-save --no-package-lock playwright@1.64.1
node (Join-Path $employerTestTools 'node_modules/playwright/cli.js') install chromium
$env:PLAYWRIGHT_MODULE = Join-Path $employerTestTools 'node_modules/playwright/index.mjs'
$env:UI_PYTHON = (Get-Command python).Source
node frontend/tests/employer.browser.mjs
```

脚本包含建库、迁移、测试数据、服务启动与清理，不依赖先前临时脚本或 manifest。任何断言失败均返回非零退出码；项目依赖配置保持原样。
