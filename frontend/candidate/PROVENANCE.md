# 来源与修改范围

本工作区基于 GitHub 提交 8486388 与此前本地候选人扩展进行适配。它有独立入口、依赖、锁文件和配置，不覆盖 frontend/src 中的团队代码。

- 账户和资料类型通过 src/types.ts 的类型导出复用团队 frontend/src/types.ts；CSS 通过 @import 复用原样式。
- 候选人职位、申请、预约、资料编辑、纯文本展示和会话隔离代码复用此前本地实现。
- 认证、登录、注册和资料补填页包含基于团队原代码的独立派生版本；原作者归属不变，不代表其基础实现由本助手原创。
- 两个资料补填页使用最新上游版本，保留退出登录按钮；候选人表单在独立版本中增加资料编辑所需的初始值与按钮参数。
- 团队原入口不会自动挂载此工作区；使用本目录的开发命令独立运行。未来由相应文件的所有者决定主入口接入方式。
